# v1.1.0 · 硬件加速与 qBittorrent HTTP 下载 r8 基线

适用设备为 Cisco vEdge 1000（Cavium CN6130），基于 OpenWrt 25.12.6 和 Linux 6.12.112。延续 v1.0.0 的 SFP 模式识别、热插拔、OpenClash 和 LuCI 功能。
# 注意，本版本中的qbittorrent为专用硬件加速版本，不要更改可执行文件，否则可能导致硬件加速失效。
- 集成 Octeon SHA-1、SHA-256 和 AES-CBC 加速及测试工具。libtorrent 2.0.15-r2 接入硬件 SHA，内核包含 IPsec 支持（未搭建链路测试）和 AES-CBC 硬件加速模块。
- 集成 qBittorrent 5.3.0-r8、LuCI 管理页和离线 DB-IP Country Lite 2026.11。默认 WebUI 监听所有本机地址，下载目录在 WebUI 配置。qbittorrent默认调用硬件SHA内核进行校验加速，受限于外部USB控制器目前测得最高速度在270-280MB/S左右（实际内存中测试可达450MB/S），同时保持CPU低占用。
- 加入 LuCI 磁盘管理及外置盘自动扫描和挂载，挂载目录默认权限为 0777。保留 SFTP 服务。
- 在qBittorrent WebUI中加入HTTP下载功能，可以将下载完成的文件获取到本地 （「文件 → HTTP 下载」），支持 HTTP Range。
- 本版本适合作为下载机和VPN隧道终端使用
`*-squashfs-sysupgrade.tar` 已在 vEdge 1000 实机上验证保留系统设置和 qBittorrent 配置升级。附件同时提供 `*-source.tar.zst` 构建归档、软件包清单和配套 APK 包。下载后可用 `SHA256SUMS-v1.1.0.txt` 核对。
