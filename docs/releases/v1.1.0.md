# v1.1.0 · 硬件加速与 qBittorrent HTTP 下载 r8 基线

适用设备为 Cisco vEdge 1000（Cavium CN6130），基于 OpenWrt 25.12.6 和 Linux 6.12.112。延续 v1.0.0 的 SFP 模式识别、热插拔、OpenClash 和 LuCI 功能。

- 固化 vEdge 1000 的 LED 默认配置。
- 集成 Octeon SHA-1、SHA-256 和 AES-CBC 加速及测速工具。libtorrent 2.0.15-r2 接入硬件 SHA，内核包含 IPsec 支持和 AES-CBC 加速模块。
- 集成 qBittorrent 5.3.0-r8、LuCI 管理页和离线 DB-IP Country Lite 2026.11。默认 WebUI 监听所有本机地址，下载目录在 WebUI 配置。保留 Simple pread/pwrite、4 个校验线程及 32 MiB 校验队列。
- 加入 LuCI 磁盘管理及外置盘自动扫描和挂载，挂载目录默认权限为 0777。保留 SFTP 服务。
- qBittorrent WebUI 的「文件 → HTTP 下载」可下载可读的外置盘文件，支持 HTTP Range。r8 修复保留旧配置升级后 qBittorrent 的配置目录权限。

`*-squashfs-sysupgrade.tar` 已在 vEdge 1000 实机上验证保留系统设置和 qBittorrent 配置升级。附件同时提供 `*-source.tar.zst` 构建归档、软件包清单和配套 APK 包。下载后可用 `SHA256SUMS-v1.1.0.txt` 核对。
