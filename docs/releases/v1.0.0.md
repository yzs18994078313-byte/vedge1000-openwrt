# v1.0.0 · SFP、LED 和 OpenClash 基线

适用设备为 Cisco vEdge 1000（Cavium CN6130），基于 OpenWrt 25.12.6 和 Linux 6.12.112。

- 修复八个 SFP 口的模块识别与链路恢复。插入模块后读取 EEPROM 并选择 SGMII 或 1000BASE-X，模块可以在接入网线前完成模式选择。保留模块热插拔支持。
- 修正 SFP 口面板 LED 的映射和默认触发方式。
- 预装中文 LuCI、Argon 主题、WireGuard、DDNS、SQM、USB 存储支持和网络诊断工具。
- 集成 OpenClash 0.48.002 和为 Octeon 构建的 Mihomo 内核（软浮点）。
- 本版本功能较为基础，已经实现8个SFP接口和MGMT接口的识别和驱动，适合作为基础的稳定版本做后续开发。

`*-squashfs-sysupgrade.tar` 用于从兼容的 OpenWrt 系统升级。`*-initramfs-kernel.bin` 通过 U-Boot 从 RAM 启动。原始源码、feeds 和构建依赖收录在 `*-source.tar.zst`。下载后可用 `SHA256SUMS-v1.0.0.txt` 核对。
