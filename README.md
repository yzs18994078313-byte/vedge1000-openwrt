# vEdge 1000 OpenWrt

适用于 Cisco vEdge 1000（Cavium CN6130，OpenWrt 目标 `octeon/generic`）的定制固件。

[v1.0.0](../../releases/tag/v1.0.0) 是 SFP、LED 和 OpenClash 基线。Release 附件包括 OpenWrt 升级包 `.tar`、RAM 启动镜像 `.bin`、完整源码构建归档和校验清单。

[版本功能与附件说明](docs/releases/v1.0.0.md)

`source/` 对应本版本 OpenWrt 源码、feeds、内核补丁和构建配置。完整构建依赖和缓存见 Release 的 `*-source.tar.zst`。
